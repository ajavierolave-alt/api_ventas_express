Documentación del API de Ventas

Este documento proporciona información sobre cómo consumir el API de ventas.

Base URL

La URL base para acceder al API es: http://localhost:3000/api

Rutas Disponibles

1. Crear Venta

Ruta: /ventas

Método: POST

Descripción: Crea una nueva venta.

Parámetros:

  • producto (string): Nombre del producto vendido.
  • cantidad (integer): Cantidad vendida.
  • precio (float): Precio del producto.

Ejemplo de solicitud:

{
    "producto": "Zapatos",
    "cantidad": 2,
    "precio": 50.00
}

Ejemplo de respuesta:

{
    "mensaje": "Venta creada exitosamente",
    "venta": {
        "id": 1,
        "producto": "Zapatos",
        "cantidad": 2,
        "precio": 50.00
    }
}

2. Obtener Ventas

Ruta: /ventas

Método: GET

Descripción: Obtiene una lista de todas las ventas.

Ejemplo de respuesta:

[
    {
        "id": 1,
        "producto": "Zapatos",
        "cantidad": 2,
        "precio": 50.00
    },
    {
        "id": 2,
        "producto": "Camisa",
        "cantidad": 1,
        "precio": 20.00
    }
]

3. Actualizar Venta

Ruta: /ventas/:id

Método: PUT

Descripción: Actualiza una venta existente.

Parámetros:

  • id (integer): ID de la venta a actualizar.
  • producto (string): Nombre del producto vendido.
  • cantidad (integer): Cantidad vendida.
  • precio (float): Precio del producto.

Ejemplo de solicitud:

{
    "producto": "Zapatos",
    "cantidad": 3,
    "precio": 45.00
}

Ejemplo de respuesta:

{
    "mensaje": "Venta actualizada exitosamente",
    "venta": {
        "id": 1,
        "producto": "Zapatos",
        "cantidad": 3,
        "precio": 45.00
    }
}

4. Eliminar Venta

Ruta: /ventas/:id

Método: DELETE

Descripción: Elimina una venta existente.

Parámetros:

  • id (integer): ID de la venta a eliminar.

Ejemplo de respuesta:

{
    "mensaje": "Venta eliminada exitosamente"
}
